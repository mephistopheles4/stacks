Everything else in each room (wall, floor, rug, table, candles, lamp) is built by
`build_room.py`.

With `--lightmaps`, the floor, the rug and its fringe bake light only (`light/<room>-*.jpg`,
made here), and the page lays these textures over it. `tex/rug-fringe.jpg` (the fringe's
cotton) and `tex/rug-pile.jpg` (the pile grain) are generated by `rug.py`, made here.

⚠️ **`room-trellis.glb` must not ship as it is, and is not committed**: it stays on
the machine that made it. The Met photo had no alpha
channel, so the Space cut the chair out with `briaai/BRIA-RMBG-2.0`, which is
licensed for non-commercial use only. The Space skips that step for an image that
already has an alpha channel, so a shippable chair means masking the photo first
(BiRefNet, MIT, or by hand) and uploading that PNG.
