# The mark

Four bars: a full line, a broken one with a dot past the break, a third line.
One 64-unit viewBox, `rx="5.5"` on every bar, bars `y=12 / 26.5 / 41` at height
11. Three colourways of the same geometry.

| File | Colours | Used by |
| --- | --- | --- |
| `stacks-mark.svg` | ink, rust, ochre | `scripts/make-icons.ts` → `apple-touch-icon.png` |
| `stacks-mark-inverse.svg` | board, rust, ochre | the page header, inlined by `src/pages/index.astro` |
| `stacks-mark-mono.svg` | `currentColor` | nothing yet — for a surface that has one ink |

`packages/site/public/favicon.svg` is the same artwork on a paper tile with
`rx="12"`, and is the source the two favicon PNGs are rasterised from. The
touch icon comes from `stacks-mark.svg` instead, because iOS masks the corners
itself and the tile's would be rounded twice.

The PNGs are committed, and regenerated by hand when the artwork changes:

```
pnpm tsx scripts/make-icons.ts
```

G13 allows them by exact filename — the mark was drawn for this app, so the
provenance claim that allowlist exists to make is as clean here as it gets. See
[ADR-0035](../../../../docs/adr/0035-brand-icons-are-generated.md).

The share card is not here either. `packages/core/src/og-image.ts` draws the
mark from the same geometry in code, because core does not reach into the site
package for four rectangles; if the mark ever changes shape it changes in both
places, and a comment there says so.

## Palette

`#1E1B18` ink · `#B4472E` rust · `#C98A2B` ochre · `#EBDCC4` board ·
`#FBF6EC` paper

The page is none of these — it is a lit room, `#1a1613` behind wood and warm
lamplight, and predates the mark. The palette governs the surfaces seen on
somebody else's background: the icons, and the share card.

## Wordmark

Lowercase, IBM Plex Mono 500, `letter-spacing: -0.02em`. **The font is not
shipped** — the header asks for it and falls back to the platform's monospace,
because one request and ~30 KB for six letters is a poor trade on a page whose
first paint is a WebGL scene.
